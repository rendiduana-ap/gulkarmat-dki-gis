1. Hosting Website Nama Sendiri (Gratis 100%) SIAP PRESENTASI

Jadikan aplikasi ini website mandiri dengan nama domain pilihan Anda sendiri (misalnya gulkarmat-dki.netlify.app atau gis-damkar-jakarta.vercel.app):

  1. Klik "Unduh index.html" di bawah untuk menyimpan file website lengkap beserta seluruh database pos & sumber air gedung.
  2. Unggah secara gratis ke salah satu layanan berikut:
    • Netlify Drop (app.netlify.com/drop): Tarik & lepas folder berisi index.html, lalu ubah nama situs menjadi gulkarmat-dki.netlify.app.
    • GitHub Pages (github.com): Buat repositori baru, upload index.html, dan aktifkan Settings → Pages.
    • Vercel (vercel.com): Deploy instan untuk domain .vercel.app gratis.
